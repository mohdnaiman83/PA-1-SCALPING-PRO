# Coding Standard

## Principles

One Module

One Responsibility

One Owner

Read Don't Rewrite

No Duplicate Logic

No Hidden State

---

Configuration

Global Variables

Functions

## Modules

Each module must contain:

Header

Purpose

Inputs

Outputs

Owner

Dependencies

Consumers

## Rule

Performance optimization must never change trading logic.
